name: chairlift
description: Repository guidance for working on ChairLift
---

Before changing ChairLift, read and follow `AGENTS.md`, `docs/SKILL.md`, the
matching package in `docs/skills/`, and the relevant architecture
documentation in `docs/design/`. If the host provides a prior handoff in its
non-committed session/workspace directory, read it there; do not look for or
create a tracked session note. Before handing unfinished work to another
session, write a compact handoff there with the objective, completed work,
validation, remaining work, and relevant repository context. Durable learnings
belong in `docs/skills/`; verified corrections belong in `.memory/`.
