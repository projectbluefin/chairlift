# Factory references

Local scope, safety and delivery rules are in [AGENTS.md](../../AGENTS.md) and
[CONTRIBUTING.md](../../CONTRIBUTING.md). Use the
[local merge/release procedure](../skills/factory-onboarding/SKILL.md) only for
those operations.

For cross-repository work, consult Common's live
[agentic model](https://github.com/projectbluefin/common/blob/main/docs/factory/agentic-model.md),
[human gates](https://github.com/projectbluefin/common/blob/main/docs/skills/human-gates.md)
and [Prow workflow](https://github.com/projectbluefin/common/blob/main/docs/skills/label-workflow.md).
Assignment, issue acceptance, review approval and delivery are separate facts;
verify live state before acting. Linked policy does not bypass local review or
the merge queue.
